# Research note: branded decks, assessment items and surveys without a server

Date: 22 October 2026, evening. For the depth plan: what pptxgenjs can and cannot do for a branded, editable, accessible deck; how to preview slides in the browser; the item and rubric formats an LMS accepts; and how a local-first app can collect student survey responses. Compiled in a research session on 22 October 2026; vendor pages marked **V**, unverified items marked.

## 1. pptxgenjs capabilities and limits

- The current release is 4.0.1 (26 June 2025); 4.0.0 (4 May 2025) added text direction and fixed master reuse. MIT. https://github.com/gitbrent/PptxGenJS/releases
- **Masters**: `defineSlideMaster({ title, background, margin, objects: [rect, line, text, image, placeholder], slideNumber })`; placeholders are named objects of type title, body, image, chart, table or media, filled with `addText(..., { placeholder: "body" })`; masters become editable layouts under View, Slide Master. https://gitbrent.github.io/PptxGenJS/docs/masters/
- **Images**: PNG, JPG and GIF; SVG "supported in the newest desktop PowerPoint or Microsoft 365" with no documented fallback, so ship a PNG raster of the institution's logo and the SVG only as an extra; sizing contain, cover and crop; image hyperlinks. https://gitbrent.github.io/PptxGenJS/docs/api-images/
- **Charts**: area, bar, bar3d, bubble, doughnut, line, pie, radar, scatter and combo as native chart XML with an embedded workbook. https://gitbrent.github.io/PptxGenJS/docs/api-charts/
- **Tables**: colspan and rowspan, per-cell formatting, auto-paging with a repeated header ("not an exact science"). https://gitbrent.github.io/PptxGenJS/docs/api-tables/
- Notes with `slide.addNotes()`, sections with `pptx.addSection()`, hyperlinks to a URL or a slide, `fit: shrink` or `resize`, bullets with indent levels. https://gitbrent.github.io/PptxGenJS/docs/speaker-notes/
- **Theme**: only head and body font faces and language; no theme colour palette API, but scheme colours are accepted in colour and fill. Layouts 16:9 (10 by 5.625 inches), wide, or custom. https://gitbrent.github.io/PptxGenJS/docs/usage-pres-options/
- **Limits**: no font embedding; animations are not on the roadmap; it cannot edit an existing PPTX.
- **Known defects**, issue 1449 (opened 31 March 2026, still reproducing on 4.0.1 in September): string shape presets such as `"oval"` and `"roundedRectangle"` write invalid XML (use the `pres.shapes` constants), one slide-master content-types override per slide, a malformed notes master; the issue carries a post-process repair function. https://github.com/gitbrent/PptxGenJS/issues/1449
- **Thumbnails without PowerPoint**: LibreOffice headless to PDF then pdftoppm (https://help.libreoffice.org/latest/en-US/text/shared/guide/start_parameters.html); pptx-glimpse renders PPTX to SVG or PNG in Node 22 or the browser, "not pixel-identical" (https://cdn.jsdelivr.net/npm/pptx-glimpse/README.md); pptx-browser 4.1.5 draws on a canvas (https://cdn.jsdelivr.net/npm/pptx-browser@4.1.5/README.md); Microsoft Graph converts to PDF or JPG with a 2 MB cap and a sign-in (https://learn.microsoft.com/en-us/graph/api/driveitem-get-content-format) **V**. Cheapest and most faithful for Lyceum: render Lyceum's own slide spec to SVG in React, and rasterise with Puppeteer only for export.

## 2. Alternatives for slide generation

- python-pptx (MIT, 1.0.0): placeholders, charts, tables, notes; no rendering. https://python-pptx.readthedocs.io/en/latest/
- Marp CLI (MIT): `--pptx` exports images plus notes; `--pptx-editable` is experimental and needs a browser and LibreOffice Impress, with "lower slide reproducibility" and no notes. https://github.com/marp-team/marp-cli/blob/main/README.md
- Slidev (MIT): PPTX as images by default; an editable mode rebuilds native shapes but SVG, maths and gradients stay pictures. https://sli.dev/guide/exporting
- reveal.js (MIT): PDF through the browser or decktape; no PPTX. https://revealjs.com/pdf-export/
- Google Slides API: `batchUpdate` creates native slides from layouts with OAuth; PPTX through Drive export. https://developers.google.com/workspace/slides/api/guides/overview **V**
- Microsoft Graph has no PowerPoint content API. An Office Add-in can call `PowerPoint.Presentation.insertSlidesFromBase64(base64, { formatting: "UseDestinationTheme" })` (PowerPointApi 1.2), so a pptxgenjs deck can be dropped into a university's own template inside PowerPoint. https://learn.microsoft.com/en-us/javascript/api/powerpoint/powerpoint.presentation **V**
- Editable text comes from pptxgenjs, python-pptx, the Slides API and Office.js; Marp and Slidev defaults and reveal.js give images only.

## 3. Assessment item formats and generation

- **QTI 3.0**, final in May 2022 (https://www.1edtech.org/standards/qti/versions). From the best-practice guide: a multiple-choice item declares a single-cardinality identifier response, a correct response, a float SCORE outcome, a choice interaction with one max choice and simple choices, and the match-correct response-processing template; short answer uses a text-entry interaction (expected length, pattern mask, placeholder); essay uses an extended-text interaction (expected lines, min and max strings, plain, preformatted or xhtml) with no automatic scoring; a rubric block takes a view (author, candidate, scorer and so on); a package is a zip with an IMS manifest. https://www.imsglobal.org/spec/qti/v3p0/impl
- **What the LMSs import**: Canvas New Quizzes imports QTI 1.2 and 2.x (https://community.canvaslms.com/docs/DOC-26303); Blackboard Ultra banks import QTI 2.1 for true or false, multiple choice, multiple answer, fill in the blank and essay (July 2025) **V**; Moodle imports Moodle XML, GIFT and Aiken, not QTI 3.
- **Moodle XML** (https://docs.moodle.org/en/Moodle_XML_format, checked against Moodle 4.5 source): `<question type="multichoice|shortanswer|essay">`, `<name><text>`, `<questiontext format="html"><text><![CDATA[...]]>`, `<answer fraction="100"><text>` with `<feedback>`; multichoice has `<single>`, `<shuffleanswers>`, `<answernumbering>` and the three feedback elements; shortanswer `<usecase>`; essay `<responseformat>`, `<responserequired>`, `<responsefieldlines>`, word limits, attachments, `<graderinfo>`, `<responsetemplate>`; UTF-8 with the XML declaration alone on line 1.
- **Bloom verbs** (University of Arkansas, 26 July 2022, CC BY-NC-ND): Remember list, define, name, label, recall; Understand describe, explain, paraphrase, summarise, interpret; Apply calculate, predict, solve, demonstrate, use; Analyse classify, categorise, diagram, break down; Evaluate judge, defend, justify, argue; Create design, formulate, compose, develop. https://tips.uark.edu/using-blooms-taxonomy/
- **Item-writing rules**: Haladyna, Downing and Rodriguez 2002 (Applied Measurement in Education 15(3)): 31 guidelines in five groups (content, format, style, the stem, the choices). https://eric.ed.gov/?id=EJ660246. The rules a deterministic generator can enforce: a positive stem that carries the main idea; three options suffice; one keyed answer in varied positions; independent, homogeneous options of equal length; no "all of the above" or "none of the above"; distractors from common errors; no absolutes or grammar clues; no trick items. https://cpl.health.unm.edu/AssetListing/Writing-Questions-for-Learning-and-Assessment-JiTL-2573/Rules-for-Multiple-Choice-Items-Haladyna-et-al-2002-5943
- **Rubrics**: the AAC&U VALUE rubrics (2009; CC BY-NC-SA 4.0, attribution required, commercial use needs permission, adaptations share alike). https://www.aacu.org/value/how-to-cite. Ship the four-level grid shape (capstone, two milestones, benchmark) with lecturer-written descriptors, and link rather than bundle the AAC&U text.

## 4. Survey collection without a server

- **Microsoft Forms** has no create API ("Creating forms directly through an API in Microsoft Forms isn't supported", Microsoft Q&A, 3 January 2025, https://learn.microsoft.com/en-us/answers/questions/2139869/creating-microsoft-forms-via-graph-api-in-power-au); Quick Import builds a form from a Word or PDF file (10 MB, local file only; matching and multi-blank items become open text). https://support.microsoft.com/en-us/forms/convert-a-word-or-pdf-form-or-quiz-to-microsoft-forms **V**. **Google Forms API**: `forms.create` plus `batchUpdate` with OAuth, 375 writes a minute per project; forms created by the API after 30 June 2026 start unpublished. https://developers.google.com/workspace/forms/api/limits **V**
- **The form in the URL**: lz-string `compressToEncodedURIComponent` (MIT, https://github.com/pieroxy/lz-string); a fragment never reaches a server; keep links under about 2,000 characters. Answers return as a short base64 token the student pastes into the LMS or an email.
- **QR to a static page with a collector**: the qrcode npm package (MIT; byte mode holds 2,953 characters at level L, https://cdn.jsdelivr.net/npm/qrcode/README.md); Formspree free tier 50 submissions a month, cross-origin AJAX, a 30-day archive (https://formspree.io/plans/) **V**; Basin free tier one form, 50 a month **V**; a Google Apps Script web app posting into a Sheet (6 minutes per execution, https://developers.google.com/apps-script/guides/services/quotas) **V**; Cloudflare Workers free tier 100,000 requests a day with KV at 100,000 reads and 1,000 writes a day (https://developers.cloudflare.com/workers/platform/limits/, https://developers.cloudflare.com/kv/platform/limits/) **V**.
- **Imports**: Microsoft Forms Excel exports ID, Start time, Completion time, Email, Name, then one column per question, with Name and Email blank when anonymous (https://support.microsoft.com/topic/02859424-341d-406f-b32a-9a0fbaf357af) **V**; Google Forms exports Timestamp first, Email Address only if collected, question text as headers, CSV unsorted, timestamp text locale-dependent (https://support.google.com/docs/answer/139706); Qualtrics exports CSV, TSV, XLSX and SPSS **V**; Moodle Feedback exports CSV, XLSX, HTML, JSON and ODS (https://docs.moodle.org/405/en/Data_formats).
- **The tools universities use**: Microsoft Forms inside the Microsoft 365 tenant, Google Forms, Qualtrics, EvaSys, LMS surveys. UTP runs two Moodle instances (ULearn and ULearnX) integrated with Microsoft 365 (a Pukunui case study, undated, https://pukunui.com.my/universiti-teknologi-petronas/) **V**; https://ucs.utp.edu.my/knowledgebase/article/KA-01294/en-us

## 5. Anonymity and consent

- McGill (Senate, 23 April 2014): a minimum of five responses for classes of 5 to 11, then 40, 35, 30 and 25 percent by size; nothing disclosed to the instructor before final grades are processed; comments confidential to the instructor and the unit head. https://www.mcgill.ca/mercury/about/policy
- McLennan: five per section, results after grades (https://mclennan.edu/data/Course%20Evaluations/evaluation-faqs.html); UNC Charlotte: three (https://myevals.charlotte.edu/faqs/); Ruhr University Bochum: reports from ten cases, raw free text excluded unless categorised (February 2024).
- GDPR: Edinburgh Napier relies on the public task basis and warns that confidentiality holds "unless students identify themselves in free-text comments" (https://documentcentre.napier.ac.uk/-/media/files/university-governance/privacy-notice/privacynoticemoduleevaluation.pdf); Göttingen pseudonymises with transaction numbers.
- Malaysia: PDPA 2010 as amended in 2024, phased in during 2025 (a data protection officer, breach notification, fines up to RM 1 million); section 3 exempts the federal and state governments and the coverage of public universities is unsettled (https://amcham.com.my/malaysian-personal-data-protection-act-2010-does-it-apply-to-government-agencies/). UTP is run by a private company, whose privacy notice for students (updated June 2025) applies: https://www.utp.edu.my/sites/Publishing/PublishingContent/privacy-notice-general.pdf

## 6. Institutional slide templates

- Bath: one template for all staff, 16:9, full-screen intro, title variants, content slides, "designed to meet accessibility requirements" (https://www.bath.ac.uk/guides/using-university-branded-templates/); Manchester: the logo top-left on every slide, three background families (https://www.staffnet.manchester.ac.uk/brand/visual-identity/guidelines/presentations/); Yale: a brand typeface with a system-font fallback deck (https://yaleidentity.yale.edu/guidelines/presentations); CMU: three templates in Open Sans and Source Serif Pro (https://brand.cmu.edu/resources/downloads). The pattern: a title slide (logo, title, course, lecturer), section headers, content slides, a closing slide; a footer of course code, week and slide number is lecturer practice rather than a brand rule.
- UTP publishes no brand kit; its site describes the logo (a floral bud with the Twin Towers outline, in gold and blue). The owner's SVG is the source of truth and its hex values (#004A84 blue, #BC893A gold) come from it. https://utp.edu.my/Pages/Students/Current/Academic%20Regulations%20and%20Procedure/General-Information.aspx
- **Accessibility Checker rules for PowerPoint**: errors are missing alt text, a slide without a title, default section names and restricted access; warnings are table structure, text contrast, captions and reading order; tips are unique section names and slide titles (https://support.microsoft.com/en-ie/office/rules-for-the-accessibility-checker-651e08f2-0fc3-4e10-aaca-74b4a67101c1) **V**. Microsoft's guidance: 18 pt or larger, a sans serif, unique titles, built-in layouts for reading order, descriptive links, no colour-only meaning. WCAG2ICT (W3C Group Note, 11 December 2025) maps WCAG 2.x to non-web documents: https://www.w3.org/TR/wcag2ict-22/

## Recommended design for Lyceum

1. **Decks**: keep pptxgenjs 4.0.1; a `Brand` record (a palette, head and body fonts, the logo as a PNG rasterised from the owner's SVG, the SVG as an extra) drives five slide masters (title, section, content, two-column, closing) with named placeholders; notes on every slide; a section per week; every slide titled; objects added in reading order; body text 18 pt or larger.
2. **Deck preview**: render the same slide spec to SVG in React (no PowerPoint needed); pptx-glimpse in Node as the thumbnail and regression renderer; LibreOffice-to-PDF only in a check; shapes through the `pres.shapes` constants plus the issue-1449 repair pass.
3. **Deck fallback**: an Office Add-in calling `insertSlidesFromBase64` with the destination theme when a university supplies its own template; the Google Slides API for Workspace campuses. Both planned.
4. **Items**: deterministic templates keyed by Bloom level and item type, using the Arkansas verb list and the course's outcome records; a Haladyna lint (three or four options, equal length, a positive stem, no all-or-none options, distractors from recorded misconceptions).
5. **Item export**: Moodle XML first (UTP's ULearn is Moodle), a QTI 2.1 package second (Canvas, Blackboard Ultra), QTI 3.0 third, all from one item model; rubrics as a four-level grid exported to DOCX and XLSX and as a QTI rubric block for scorers.
6. **Surveys**: survey definitions as JSON in the workspace with two templates (the per-outcome self-rating on 1 to 5, the teaching survey); every question carries a stable id embedded in its text so imports match.
7. **Collection, primary**: a DOCX export shaped for Microsoft Forms Quick Import (Microsoft 365 campuses) and Google Forms through its API when signed in.
8. **Collection, fallback**: a static responder page on the public site, opened by QR, with the form in the URL fragment through lz-string, posting to a Cloudflare Worker with KV (the free tier covers a course) or Formspree; the last resort a paste-this-code token.
9. **Results back**: importers for Microsoft Forms XLSX, Google Forms CSV, Moodle Feedback CSV and XLSX, and Qualtrics CSV through SheetJS, matched on the question id; aggregates only at five responses or more; free text locked until the lecturer marks grades released; a consent line and the privacy notice on every form; no identifiers stored.
10. **Verification**: golden-file tests per writer (PPTX XML diff, a Moodle XML import into a local Moodle, QTI validated against the 1EdTech schema) beside the existing checks.
